## Известные проблемы

Среда разработки (проверено командами 2026-09-21, см. `docs/questions.md` Q1):

1. **Go собран под 386.** `go version` → `go1.27.0 windows/386`. Нужен `windows/amd64`: 32-битная сборка упирается в память на линтерах и тестах, часть инструментов её не поддерживает.
2. **Docker не запущен и не может запуститься.** `docker info` → нет `dockerDesktopLinuxEngine`; `wsl` сообщает, что подсистема Windows для Linux не установлена. Без этого не поднимутся PostgreSQL, Redis, MinIO, ClamAV, converter и testcontainers — то есть не работает ни `make dev`, ни `make check`.
3. **Нет `make`.** Все критерии приёмки сформулированы как `make ...`.
4. **Нет `pnpm`** (есть `npm 11.12.1`) — стек допускает оба, нужно зафиксировать один.
5. **Проект лежит в OneDrive и в пути есть пробел** (`.../Desktop/aifc/Docx auto`). OneDrive синхронизирует `.git` и `node_modules` — это блокировки файлов, порча индекса git и мусорный трафик. Пробел в пути ломает часть Go- и Docker-инструментов.

Проблемы предметной области, найденные при чтении и ещё не решённые, — в `docs/questions.md`.
