# Ночной бэкап исходного кода

«Тест день 3»: «добавить автобэкап на сервера: сохраняет копию, но не
трогает оригинал, просто сохраняет исходный код, чтобы не потерять всё,
каждые 24 часа в 00:00, а старый автоматом удалять».

## Что делает

Каждый день в 00:00 `scripts/backup/backup.ps1`:

1. Собирает снимок папки проекта – всё, что не исключено `.gitignore`
   (`node_modules`, `dist`, `.env` в снимок не попадают), **включая правки,
   которые ещё не закоммичены**.
2. Кладёт снимок в ветку `backup/ГГГГ-ММ-ДД` на GitHub (`origin`).
3. Удаляет ветки старше семи последних снимков.

Оригинал не трогается: снимок собирается во временном индексе git, рабочие
файлы, настоящий индекс и текущая ветка остаются как были. Проверено
прогоном вхолостую 25.09: хеш `.git/index`, `HEAD` и `git status` до и
после одинаковые.

Журнал: `%LOCALAPPDATA%\DocFlow\backup.log`.

## Установка

**Сначала репозиторий на GitHub должен быть приватным**: снимок уходит
туда целиком, а в коде лежат реквизиты компаний. GitHub → репозиторий →
Settings → Danger Zone → Change visibility → Private.

Затем в PowerShell из папки проекта:

```powershell
.\scripts\backup\backup.ps1 -DryRun        # проверка вхолостую, ничего не отправляет
.\scripts\backup\backup.ps1                # первый снимок сейчас
.\scripts\backup\install-backup-task.ps1   # задача Windows на 00:00
```

Задача работает, пока пользователь вошёл в Windows. Если в 00:00 компьютер
выключен или спит, снимок снимется при следующем включении.

Снять задачу: `.\scripts\backup\install-backup-task.ps1 -Remove`.
Хранить больше снимков: параметр `-Keep`, например `backup.ps1 -Keep 30`
(для задачи – поправить аргументы в планировщике).

## Восстановление

Посмотреть, какие снимки есть:

```powershell
git ls-remote --heads origin "backup/*"
```

Достать снимок в отдельную папку, не трогая рабочую:

```powershell
git clone --branch backup/2026-09-25 git@github.com:MirasDavletaly/DockFlow.git DockFlow-restore
```

Или в ту же папку отдельной веткой:

```powershell
git fetch origin backup/2026-09-25
git switch -c restore-2026-09-25 FETCH_HEAD
```

Родитель снимка – коммит, на котором стояла папка в ту ночь, поэтому вся
история на месте.

## Чего бэкап не делает

- **Не сохраняет данные сайта.** Документы, персонал и учётные записи
  лежат в браузере каждого пользователя (`localStorage`), а не в папке
  проекта. Их бэкап появится вместе с сервером и базой
  (`docs/plans/phase-01-server.md`).
- **Не отправляет `main`.** Основная ветка отправляется обычным
  `git push`; ночной снимок лежит рядом и её не переписывает.
